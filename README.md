# GPdx

**GPdx** 是一款面向学习交流的场景化工具产品。本 GitHub 仓库仅发布 **产品介绍、官网入口与功能说明文档**，便于查阅与反馈文档问题。

> **说明**：本仓库 **不包含、也不分发** GPdx 产品源代码。软件由官方独立部署与运营，请以官网及本文档为准。
